    API REST¶

    Prefixo base /api. Documentação interativa gerada pelo FastAPI disponível em /docs (Swagger UI) e /redoc enquanto o servidor estiver em execução.

    Níveis de autenticação

    Nível Descrição
    PUBLIC Sem token
    OPT Bearer ou ?token= (necessário para EventSource e <img>)
    USER JWT access no header Authorization: Bearer <token>
    ADMIN JWT de administrador

    Autenticação · /api/auth¶

    POST /api/auth/register · PUBLIC · 201¶

    Cria uma nova conta. O primeiro usuário registrado torna-se administrador automaticamente.

    Campo Tipo Regra
    email string e-mail válido
    username string 3–50 caracteres
    password string mínimo 6 caracteres

    POST /api/auth/login · PUBLIC · 200¶

    Login com username (aceita e-mail ou nome de usuário) e senha. Retorna access_token e refresh_token. Formato application/x-www-form-urlencoded (OAuth2).

    Campo Tipo
    username string
    password string

    POST /api/auth/refresh · PUBLIC · 200¶

    Renova o access_token a partir do refresh_token.

    Campo Tipo
    refresh_token string

    POST /api/auth/forgot-password · PUBLIC · 200¶

    Envia e-mail de redefinição de senha.

    Campo Tipo
    email string

    POST /api/auth/reset-password · PUBLIC · 200¶

    Redefine a senha usando o token recebido por e-mail.

    Campo Tipo Regra
    token string token enviado por e-mail
    nova_senha string mínimo 6 caracteres

    GET /api/auth/me · USER · 200¶

    Retorna perfil do usuário autenticado.

    GET /api/auth/me/historico · USER · 200¶

    Retorna buscas recentes do usuário.

    Query param Tipo Padrão
    limite int 50

    GET /api/auth/me/historico/{search_id} · USER · 200¶

    Proteínas de uma busca histórica específica.

    DELETE /api/auth/me/historico/{search_id} · USER · 204¶

    Remove uma busca do histórico.

    PUT /api/auth/me/senha · USER · 200¶

    Altera a senha do usuário autenticado.

    Campo Tipo Regra
    senha_atual string —
    nova_senha string mínimo 6 caracteres

    GET /api/auth/admin/usuarios · ADMIN · 200¶

    Lista todos os usuários cadastrados.

    PUT /api/auth/admin/usuarios/{user_id}/toggle-ativo · ADMIN · 200¶

    Ativa ou desativa uma conta de usuário.

    Busca e download¶

    GET /api/search/stream · OPT · 200 SSE¶

    Busca proteínas no PDB com progresso em tempo real via Server-Sent Events. Quando autenticado, salva no histórico.

    Query param Tipo Obrigatório Descrição
    proteinas string ✓ Nomes separados por vírgula
    forcar_novo bool — Ignora cache; padrão false
    limite int — Máximo de estruturas por proteína; padrão ilimitado

    GET /api/search/csv · PUBLIC · 200¶

    CSV dos resultados em cache com filtros opcionais.

    Query param Tipo Obrigatório
    proteinas string ✓
    organismo string —

    GET /api/search/organismos · PUBLIC · 200¶

    Lista organismos únicos disponíveis no cache.

    DELETE /api/search/cancelar-parcial · PUBLIC · 200¶

    Remove do banco proteínas salvas parcialmente ao cancelar uma busca.

    Campo Tipo
    proteinas_query string

    GET /api/download/pdb/{id} · OPT · 200¶

    Baixa estrutura PDB do usuário.

    GET /api/download/cif/{id} · OPT · 200¶

    Baixa estrutura CIF do usuário.

    GET /api/download/meus-pdbs · USER · 200¶

    Lista arquivos PDB do usuário.

    DELETE /api/download/meus-pdbs/{id} · USER · 204¶

    Remove vínculo do arquivo (arquivo permanece no disco).

    Query param Tipo
    formato string

    GET /api/download/visualizar/{id} · USER · 200¶

    Árvore de resíduos da estrutura.

    GET /api/download/visualizar/{id}/linhas · USER · 200¶

    Linhas brutas do arquivo PDB.

    Query param Tipo Obrigatório

    base_input_path string ✓

    Campo Tipo

    base_input_path string

    PUT /api/redocking/csv · USER · 204¶

    Salva ou atualiza o pdb_codes.csv do usuário.

    Campo Tipo Padrão
    csv_content string —
    target string ""
    base_input_path string ""

    GET /api/redocking/csv · USER · 200¶

    Retorna o pdb_codes.csv mais recente do usuário.

    ChEMBL · /api/chembl¶

    POST /api/chembl/run · USER · 200¶

    Cria job e inicia coleta de moléculas. Retorna imediatamente; use polling via GET /jobs/{id}.

    Campo Tipo Descrição
    items array Lista de alvos (ver abaixo)
    base_output_path string Pasta de saída

    Cada item de items:

    Campo Tipo Padrão Descrição
    target_name string — Nome do alvo (ex: Acetylcholinesterase)
    folder_name string — Nome da pasta de saída
    chembl_search_id string null ID ChEMBL quando o nome não resolve (ex: CHEMBL1914)
    target_filters.organism string "Homo sapiens" Organismo
    target_filters.type__in array ["SINGLE PROTEIN"] Tipos de alvo
    target_filters.relationship_type string "DIRECT" Tipo de relação
    bioact_filters.standard_type__in array ["Ki"] Tipos de bioatividade
    bioact_filters.molecule_type string "small molecule" Tipo de molécula
    bioact_filters.max_value_ref int 1000 Valor máximo de referência (nM)
    sim_filters.similarity int 60 Limiar de similaridade (%)
    sim_filters.molecular_weight__lte int 500 Peso molecular máximo (Da)

    GET /api/chembl/jobs · USER · 200¶

    Histórico de jobs ChEMBL do usuário.

    GET /api/chembl/jobs/{job_id} · USER · 200¶

    Job específico com status por item e etapa atual.

    GET /api/chembl/jobs/{job_id}/molecules · USER · 200¶

    Moléculas coletadas do job, paginadas.

    Query param Tipo Padrão
    page int 1
    per_page int 50

    GET /api/chembl/jobs/{job_id}/analysis-status · USER · 200¶

    Status da análise de fingerprints e similaridade.

    GET /api/chembl/jobs/{job_id}/networks · USER · 200¶

    Metadados das redes de similaridade (scaffold, MCC, bins).

    GET /api/chembl/jobs/{job_id}/plot/{filename} · OPT · 200¶

    Serve o PNG de análise de rede.

    POST /api/chembl/analise · USER · 202¶

    Dispara análise de fingerprints e similaridade em background.

    Campo Tipo Padrão Descrição
    job_id int — —
    fingerprint "morgan" | "maccs" | "pharmacophore" "morgan" Tipo de fingerprint
    metric "Tanimoto" | "Dice" | "Cosine" "Tanimoto" Métrica de similaridade
    base_output_path string — Pasta de saída

    DELETE /api/chembl/jobs/{job_id} · USER · 204¶

    Remove job do histórico.

    Query param Tipo Padrão Descrição

    per_page int 50 —

    hia string null Ex: HIA%2B

    GET /api/admet/results/{result_id}/download/{tipo} · USER · 200¶

    Download CSV do resultado. tipo: all | bbb_plus | bbb_minus | hia_plus | toxic.

    Clustering · /api/clustering¶

    POST /api/clustering/iniciar · USER · 202¶

    Inicia job de clustering MAIA.

    Campo Tipo Padrão Descrição
    admet_result_id int — ID do resultado ADMET
    fingerprint_type string "morgan" Tipo de fingerprint
    base_output_path string "/resultados/clustering" Pasta de saída
    max_mols int null Limita o nº de moléculas

    GET /api/clustering/{job_id} · USER · 200¶

    Status, nº de clusters e silhouette score.

    GET /api/clustering/by-admet/{admet_result_id} · USER · 200¶

    Job de clustering associado a um resultado ADMET.

    GET /api/clustering/{job_id}/plot · USER · 200¶

    PNG do scatter t-SNE.

    GET /api/clustering/{job_id}/centroid/{cluster_id} · USER · 200¶

    PNG do centroide (MCS) do cluster N.

    GET /api/clustering/{job_id}/tsne-data · USER · 200¶

    Coordenadas t-SNE como JSON para visualização interativa.

    GET /api/clustering/{job_id}/download · USER · 200¶

    CSV de clustering com colunas molecule_chembl_id, canonical_smiles, label.

    DELETE /api/clustering/{job_id} · USER · 204¶

    Remove job + NeuroDock downstream + arquivos em disco.

    DELETE /api/clustering/by-admet/{admet_result_id} · USER · 204¶

    Remove clustering + NeuroDock de um ADMET (reset de pipeline).

    Consenso · /api/consensus¶

    POST /api/consensus/iniciar · USER · 202¶

    Inicia docking de consenso para um resultado ADMET. Re-rodar sobrescreve job anterior.

    Campo Tipo Padrão Descrição
    admet_result_id int — ID do resultado ADMET
    selected_categories array — Categorias: "bbb_plus", "bbb_minus", "hia_plus", "toxic", "all"
    pdb_id string — Código PDB do receptor (ex: 4EY7)
    ligand_resname string — Nome do resíduo do ligante no PDB
    ligand_resnum int — Número do resíduo do ligante

    Inicia simulação de dinâmica molecular.

    Campos principais:

    Campo Tipo Obrigatório Descrição
    molecule_id string ✓ Identificador da molécula
    smiles string — SMILES da molécula

    Campo Tipo Padrão Descrição

    water_model string "TIP3P" Modelo de água
    protein_forcefield string "AMBER_FF14SB" Campo de força da proteína
    ligand_forcefield string "OPENFF_2_2_0" Campo de força do ligante
